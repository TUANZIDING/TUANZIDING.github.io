最重要的文件

AGENTS.md
是任务规则

它是你写给 Codex 的任务规则。Codex 进入文件夹就会照着它干活。

这是一个文献搜索任务。
研究主题：生成式 AI 对研究生科研自我效能的影响。
规则：
1. 不要凭模型记忆编造论文。
2. 所有推荐文献必须提供标题、作者、年份、来源、DOI 或可访问链接。
3. 先生成检索式，再执行检索，再整理结果。
4. 输出结果保存到 search-results/ 文件夹。
5. 不确定的信息请标记为“待核查”，不要写成确定结论。

换个任务

数据分析的
规则长这样

规则写的是边界：数据从哪来、图怎么生成、产出放哪。

这是一个问卷数据分析任务。
数据文件：data.csv
变量说明：variable-dictionary.md
规则：
1. 所有统计结果必须来自 data.csv。
2. 所有图表必须由 Python 或 R 代码生成，不要用图片生成模型直接画统计图。
3. 每一步分析都要保留代码。
4. 输出 data_quality_report.md、analysis_report.md、figures/ 和 scripts/analysis.py。
5. 如果变量不适合做某种统计分析，请先说明原因，不要硬做。

02

第二步

Skill 不是提示词，
而是成熟 SOP

同一个 Codex，配置了不同 Skill，能力会差很多。

一次性 vs 可复用

它们回答的不是同一个问题

提示词

这一次，
我怎么问 AI？

依赖模型的通用能力，每次重写，效果不稳定。

VS
Skill

以后每次遇到类似任务，
Agent 按什么流程做？

沿固定流程干活，输入、步骤、输出都可预期。

检查清单

一个好的 Skill 写清这六件事

1什么时候用
2需要什么输入
3按什么步骤执行
4能调用哪些脚本
5最后输出什么
6哪些事情不能做

提醒

别因为一个 Skill 很火，就拿来写论文

例子：K-Dense Scientific Agent Skills

0个科研 Skill

覆盖癌症基因组学、药物靶点结合、分子动力学、RNA velocity、地理空间、时间序列、科学数据库等，整体偏生物、化学、医学、组学和科学计算。

判断标准教育学、新闻传播、管理学、社会学或计算机写作方向，要看它的工作流是否适合你的研究任务，而不是热度。

装好任何 Skill 之后

先让 Codex 把它审一遍

请先不要执行任务。请阅读这个 Skill 的 SKILL.md，并用中文总结：
1. 这个 Skill 适合解决什么问题？
2. 它需要我提供哪些输入材料？
3. 它会调用哪些脚本、工具或外部服务？
4. 它最终会输出哪些文件或结果？
5. 它明确不适合做什么？
6. 结合我的研究任务，你认为这个 Skill 是否适配？如果不适配，需要改哪些规则？

不匹配怎么办

别硬用。让 Codex 基于它改一版适合自己的流程，或把实验室常用流程沉淀成自己的 Skill。

最适合写成 Skill 的例子

论文终稿检查：查数值、查图表编号、查参考文献、查统计符号、查格式、查基金号。

03

场景一

论文搜索

先生成检索路径，再真实检索。

论文搜索

最危险的问法，和正确路径

✕ 最危险的问法

“请推荐 20 篇关于生成式 AI 和研究生科研能力的论文。”

模型可能凭记忆列出一批看起来很像真的文献，没有真实检索，也没有 DOI、PMID 或数据库链接。
  1. 拆主题概念矩阵
  2. 检索式多组、各有角度
  3. 真实检索Skill / API
  4. 文献表去重、可核查

① 拆主题 · 示例：生成式 AI 对研究生科研自我效能的影响

先生成检索语言，不推荐论文

请把下面这个研究主题拆成文献检索概念矩阵：
主题：生成式 AI 对研究生科研自我效能的影响。
请输出：
1. 核心概念
2. 英文关键词
3. 同义词或近义表达
4. 可能相关理论
5. 可用于 Google Scholar 的英文检索式
6. 可用于中文数据库的中文检索式
注意：这一步只生成检索语言，不要推荐具体论文。

它可能拆出的检索入口

概念英文表达可能扩展
生成式 AIgenerative AI, ChatGPT, large language modelsAI tools, GenAI, LLMs
研究生graduate students, postgraduate studentsdoctoral students, master students
科研自我效能research self-efficacyacademic self-efficacy, research confidence
科研训练research trainingacademic writing, literature review, research productivity
技术接受technology acceptanceperceived usefulness, perceived ease of use

② 生成检索式

不要一条超长检索式

分成多组，每组只盯一个角度：科研写作、文献综述、研究自我效能、技术接受……

请基于上面的概念矩阵，生成 10 组 Google Scholar 检索式。
要求：
1. 不要只生成一条特别长的检索式。
2. 每组检索式聚焦一个角度，比如科研写作、文献综述、研究自我效能、技术接受。
3. 每组检索式后解释它主要想找到哪类论文。
4. 输出到 search-results/search-queries.md。

③ 真实检索

按学科选工具

社科 · 教育 · 管理

Google Scholar Search Skill

ClawHub 上可用，按关键词、作者、年份检索并导出元数据。

医学 · 生物医学 · 公卫

pubmed-paper-finder

把医学主题拆成多个 PubMed 检索模块，调用 NCBI E-utilities 取回 PMID、标题、期刊、年份、DOI、摘要和链接，再按相关性、证据类型、新近程度生成阅读清单。

已有论文列表

paper-quality-filter

按来源层面的证据排阅读优先级：JCR 分区、影响因子、中科院分区、CCF 等级、EI、北大核心、CSSCI、AMI、科技核心等。不判断单篇学术价值。

安装任何 Skill 都很简单：直接告诉 Codex“帮我安装某某 Skill，地址是……”。

③ 真实检索 · 两种写法

把检索交给工具，结果才可核查

请使用 Google Scholar Search Skill，基于 search-results/search-queries.md 里的 10 组检索式进行检索。
要求：
1. 每组检索式返回前 10 篇结果。
2. 合并去重。
3. 保留标题、作者、年份、来源、引用数、链接。
4. 初步判断主题相关性。
5. 输出 literature_search_results.md 和 literature_matrix.csv。
请帮我从 GitHub 安装这个 Skill：
https://github.com/yilaai/pubmed-paper-finder
安装后请先阅读 SKILL.md，告诉我它的检索流程、输入要求、输出格式和使用限制。

原则不是让 AI 凭空推荐论文，而是让 Codex 设计检索路径、执行真实检索、整理可核查结果。

场景二

综述写作

AI 擅长阅读理解，但必须基于真实论文。

前提只有一个：必须基于真实论文

顺序锁：先矩阵，再大纲，最后正文

综述要大量阅读、归纳、比较、分类，正是 AI 的强项。建议给 Codex 接入论文搜索 API，或使用已接入论文库的工具。

1主题矩阵literature_theme_matrix.md
→
2综述大纲review_outline.md
→
3正文初稿literature_review_v1.md

综述任务

文件夹和规则

literature-review/
├── AGENTS.md
├── papers/
├── literature_matrix.csv
├── notes/
└── draft/
✕ 不要直接问

“请帮我写一篇关于生成式 AI 与研究生科研能力的文献综述。”

这是一个文献综述写作任务。
规则：
1. 综述只能基于 papers/ 文件夹中的 PDF、literature_matrix.csv 和 notes/ 中的读书笔记。
2. 不得新增我没有提供或没有真实检索到的文献。
3. 每个重要观点后面必须标注文献来源。
4. 如果某个观点缺少文献支撑，请写入 unchecked_claims.md。
5. 先生成主题矩阵和综述大纲，再写正文。

点步骤切换

三步提示词

请阅读 papers/ 文件夹中的论文和 literature_matrix.csv。
先不要写综述正文，请先输出 literature_theme_matrix.md，表格包括：
1. 主题板块
2. 代表文献
3. 研究对象
4. 研究方法
5. 核心发现
6. 研究不足
7. 和我的研究问题有什么关系
注意：只能使用我提供的真实论文。不要新增文献。
请基于 literature_theme_matrix.md 生成综述大纲。
要求：
1. 不要按“张三说、李四说、王五说”排列。
2. 按研究主题和问题逻辑组织。
3. 每一节说明：这一节回答什么问题、使用哪些文献、最后要引出什么研究不足。
4. 输出 review_outline.md。
请基于 review_outline.md 和 literature_theme_matrix.md 写 literature review 初稿。
要求：
1. 每段都要有明确中心句。
2. 每个重要判断都要标注对应文献。
3. 不要写没有来源支撑的泛泛评价。
4. 不确定的地方写入 unchecked_claims.md。
5. 输出 draft/literature_review_v1.md。
综述写作最怕的不是 AI 不会总结，
而是它总结了不存在的文献。

可参考：Research-Paper-Writing-Skills

主要面向 ML/CV/NLP 论文，覆盖 Abstract、Introduction、Method、Experiments、Conclusion 的写作与自查，也适合做 claim-evidence alignment 和投稿前自审。

场景三

数据分析

让 Codex 写代码跑结果，不要让大模型直接画图。

真正麻烦的部分

清洗、缺失、统计、导表、画图、报告

Codex 能写代码、运行、看报错、改代码，再把结果存下来。

底线

数据分析结果必须通过代码和真实数据生成，不能让大模型凭空生成统计图。

示例：模拟问卷变量

ai_use_frequency使用 AI 工具的频率research_self_efficacy科研自我效能
writing_anxiety学术写作焦虑literature_skill文献阅读能力
grade年级discipline学科

点步骤切换

体检 → 计划 → 写代码运行

请读取 data.csv 和 variable-dictionary.md。
先不要做统计推断，请先完成数据质量检查：
1. 样本量是多少？
2. 每个变量的数据类型是什么？
3. 每个变量缺失值比例是多少？
4. 是否存在明显异常值？
5. 量表变量的取值范围是否符合变量说明？
6. 输出 reports/data_quality_report.md。
请基于数据质量检查结果，生成一个适合这份问卷数据的分析计划。
要求：
1. 先做描述性统计。
2. 再做相关分析。
3. 如果变量条件允许，做回归分析。
4. 每一种分析都说明使用原因、变量选择和结果解释边界。
5. 输出 reports/analysis_plan.md。
请根据 reports/analysis_plan.md 写 Python 分析代码。
要求：
1. 使用 pandas、numpy、scipy、statsmodels、matplotlib 或 seaborn。
2. 所有分析结果必须来自 data.csv。
3. 保存完整代码到 scripts/analysis.py。
4. 输出 descriptive_statistics.xlsx、correlation_matrix.xlsx、regression_results.md。
5. 生成 figures/fig1_missing_values.png、figures/fig2_correlation_heatmap.png、figures/fig3_regression_coefficients.png。
6. 不要使用图片生成模型直接画统计图。

这样生成的图才可追溯：打开 scripts/analysis.py 能看到怎么算的，也能核对 correlation_matrix.xlsx 和图是否一致。

场景四

答辩 PPT

论文写好了，不要再手搓每一页。

论文是长文本，PPT 是现场表达

核心不是换格式，而是重组答辩逻辑

defense-ppt/
├── AGENTS.md
├── final-paper.md
├── figures/
├── tables/
└── ppt-output/
这是一个硕士论文答辩 PPT 生成任务。
规则：
1. PPT 必须基于 final-paper.md 和 figures/ 中的真实图表。
2. 不要新增论文中没有的数据、结果和结论。
3. 先生成答辩大纲 outline.md，经我确认后再生成 PPT。
4. 每页只讲一个核心信息。
5. 同时生成 speech.md 作为逐页讲稿。

点步骤切换

拆逻辑 → 出大纲 → 生成 PPT

请阅读 final-paper.md。
先不要生成 PPT，请先输出 defense_logic.md，包括：
1. 这篇论文的研究问题是什么？
2. 为什么这个问题值得研究？
3. 文献综述最后引出了什么不足？
4. 本文的方法设计是什么？
5. 主要发现是什么？
6. 创新点是什么？
7. 答辩时最可能被问到的问题有哪些？
请基于 defense_logic.md 生成 12 页左右的硕士论文答辩 PPT 大纲。
要求：
1. 每页包括：页标题、核心信息、建议图表、讲述重点。
2. 结构包括：研究背景、研究问题、文献基础、研究方法、主要发现、创新点、不足与展望。
3. 不要直接生成 PPT，先输出 outline.md 等我确认。
请使用 codex-ppt skill，把 defense-ppt/final-paper.md 做成 12 页左右的硕士论文答辩 PPT。
要求：
1. 先阅读 AGENTS.md、defense_logic.md 和 outline.md。
2. 如果 outline.md 还不适合答辩，请先提出修改建议，不要直接生成 PPT。
3. PPT 使用科研答辩风，页面简洁，减少大段文字。
4. 必须保留论文中的关键图表，不要编造新数据。
5. 生成 outline.md、speech.md 和最终 .pptx。
6. 每页备注区写入对应讲稿。

codex-ppt-skill 怎么工作

从论文到可讲的 .pptx

  1. 规划大纲 + 视觉风格
  2. 样张先确认
  3. 逐页生成幻灯片图片
  4. 组装.pptx
  5. 讲稿speech.md 写进备注
npx -y skills@latest add ningzimu/codex-ppt-skill \
  --skill codex-ppt \
  --agent codex \
  --global
优点

整页图片式 PPT，视觉统一、速度快，适合快速把论文变成可讲的答辩稿。

局限

页面元素不一定能逐个编辑。要精修，就用可编辑 PPT 转换工具，或在 PowerPoint 里手动调整关键页。

可处理文章、报告、论文、课程笔记、Markdown、PDF、Word。
