# Haixiang Ding — Clinical Academic Profile

Personal academic website for Haixiang Ding, M.D., focused on trauma care, diabetic osteoporosis mechanisms, medical education, and responsible AI in medicine.

## Public website

[https://tuanziding.github.io/](https://tuanziding.github.io/)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production site is generated in `docs/` for GitHub Pages.

## Privacy

The public site excludes identity documents, licence and certificate numbers, phone numbers, original certificate scans, application materials, receipts, and metadata-bearing private photographs.
